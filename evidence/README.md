# Evidence

Everything a page may claim comes from here.

- **Demo Day page** — `demo-day-page.md`, saved by `/setup-venture`.
- **Interviews** — one file each: `interview-YYYY-MM-DD-firstname.md`.
  Quotes verbatim. Note whether the person agreed to be quoted.
- **Screenshots** — posts, replies, payment confirmations.
- **`deposits.csv`** — every deposit, any provider. The milestone count is
  paid rows minus refunded rows. Add rows with `/log`.
- **`spend.csv` + `receipts/`** — what the team spends on sampling and
  marketing. ESSEC matches this 1 for 1, up to €500, on receipts.

Customers appear as first name + initial. Emails stay in Supabase.
