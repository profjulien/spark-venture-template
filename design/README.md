# Design snapshot

A copy of the venture's Claude Design system, kept in the repo so the look
travels with the memory.

- `brand.md` — the brand guide (the design system's README).
- `tokens.json` — colours, type, spacing, radius.
- `references/` — screenshots of the sites that set the register.

The live design system on claude.ai is the source; Claude Code refreshes
this snapshot whenever the system changes. See `docs/design.md`.
